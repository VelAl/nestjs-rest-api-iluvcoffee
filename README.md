# Iluvcoffee

NestJS REST API for a coffee shop (Iluvcoffee). Built while following the official [NestJS Fundamentals](https://courses.nestjs.com/) course.

## Setup

```bash
pnpm install
```

## Run

```bash
# development
pnpm start

# watch mode
pnpm start:dev

# production
pnpm start:prod
```

## Test

```bash
# unit tests
pnpm test

# e2e tests
pnpm test:e2e

# coverage
pnpm test:cov
```
